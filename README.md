# シフトボード

小さな店舗・チーム向けのシフト管理アプリ。HTML ファイル 1 枚で動きます。

## できること

- **週 / 月 / 日のボード** — クリックで追加、ドラッグで移動、Ctrl+ドラッグで複製
- **自動割当** — 曜日ごとの必要人数に合わせて、出勤可能日・週上限・休息時間・連勤上限を守りながら不足枠を埋める
- **ルール違反の警告** — 時間の重複、休息不足、週上限超過、連勤超過、希望休との衝突
- **希望の提出と承認** — スタッフが自分の希望休・出勤希望を送り、管理者が承認するとそのままシフトになる
- **給与計算** — 時給×実働に深夜割増（22〜5時）・残業割増（1日8h超）・交通費・固定手当・加算/控除を加えた支給額
- **振込ファイル** — 銀行の総合振込にアップロードする全銀フォーマット（固定長 120 バイト、Shift_JIS 半角カナ）、振込一覧 CSV、給与明細テキスト
- **共有・書き出し** — LINE やメールに貼れるテキスト、Excel 用 CSV

## 使い方

### 1 人で使う（この端末だけ）

`index.html` をブラウザで開くだけです。データはブラウザの保存領域（localStorage）に残ります。別の端末や別の人とは共有されません。

### 複数人で使う（スタッフが希望を提出する）

このファイルは claude.ai の Artifact として公開すると、共有データベース・ログインユーザーの判定・ファイル保存の機能が有効になります。その場合：

- 所有者（管理者）はすべてのタブを使えます
- スタッフをページの共有メニューから「編集者」として招待すると、その人には **提出** 画面が表示され、自分の希望だけを送れます
- 時給・口座・給与はサーバー側の権限ルールで管理者だけが読み書きできます

公開時の権限ルール（`capabilities`）：

```json
{
  "db": { "rules": [
    { "path": "", "read": "view", "write": "owner" },
    { "path": "payroll", "read": "owner", "write": "owner" },
    { "path": "requests", "read": "owner", "write": "owner" },
    { "path": "requests/{self}", "read": "interact", "write": "interact" },
    { "path": "data/users/{self}", "read": "interact", "write": "interact" }
  ] },
  "user": { "scopes": ["profile"] },
  "downloads": {}
}
```

## 振込ファイルについて

「給与」タブの「全銀形式ファイルを保存」は、インターネットバンキングの総合振込に取り込むためのデータを作ります。送金そのものは銀行側で取り込み・承認して確定します。振込依頼人コードや改行の扱いは銀行によって異なるので、初回は少額・少人数で取り込みテストをしてから使ってください。

計算は概算です。源泉徴収や社会保険料は含みません（加算/控除欄で手入力できます）。

## データ構造（共有データベース）

| パス | 内容 |
|---|---|
| `settings/main` | 店舗名、週の始まり、休息・連勤ルール、シフト区分、必要人数、希望受付の締切 |
| `staff/<id>` | 名前、役割、色、週上限、出勤可能曜日、連携アカウント |
| `shifts/<id>` | 日付、スタッフ、種類（勤務/希望休）、開始・終了（分）、休憩、区分、メモ |
| `payroll/<staffId>` | 時給、交通費、固定手当、振込先口座（管理者のみ） |
| `payroll/_company` | 締め日、支払日、割増率、自社口座（管理者のみ） |
| `payroll/_m_<YYYY-MM>` | 月ごとの加算/控除、支払済み記録（管理者のみ） |
| `requests/<userId>` | スタッフ本人の希望一覧と承認状態 |
